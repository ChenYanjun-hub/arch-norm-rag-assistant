# 初版评测集 · 50 条 query · 使用说明

> 这是 MVP 阶段的初版评测集，可在 W1-W2 启用，W4-W5 完成扩充至 250 条。

## 评测集结构

### 字段说明

| 字段 | 说明 | 示例 |
|---|---|---|
| `id` | 唯一编号 | Q001 |
| `scenario` | 业务场景（6 类）| 规范查找 / 规范确认 / 规范解释 / 条文对比 / 计算辅助 / 边界兜底 |
| `difficulty` | 难度（4 级）| 显性事实 / 隐性事实 / 可解释推理 / 对抗样本 |
| `spec_domain` | 规范域 | 规划 / 建筑 / 消防 / 结构 / 景观 / 综合 |
| `query` | 用户问题文本 | 居住区配套幼儿园的服务半径不应大于多少米？ |
| `expected_spec` | 应引用的规范 | GB 50180-2018 |
| `expected_clause` | 应引用的条文 | 表 5.0.3 |
| `expected_answer_summary` | 理想答案摘要 | 服务半径不宜大于 300m |
| `key_elements` | 必备答题要素 | 300m;不宜大于;GB 50180-2018 |
| `trap_type` | 陷阱类型（仅对抗样本）| 编造诱导 / 作废规范测试 / 等 |

## 使用方法

### W1-W2 数据准备阶段
- 用前 20 条（Q001-Q020）做**检索效果**初步验证
- 跑通分块策略 + 向量化后，验证 Hit Rate@5 ≥ 80%

### W2 末 · 核心问答模块跑通后
- 用 50 条全量做**端到端评测**
- 重点观察：生成层 7 维度得分、引用准确性

### W3-W4 · 持续评测
- 每周新增 30-50 条扩充至 200-250 条
- 重点补充：条文对比、计算辅助、边界兜底子情境

### W5 · 集中验收
- 用完整 250 条做最终评测
- 综合得分 ≥ 75 + 一票否决项 0 = 验收通过

## 评测打分模板（参考）

| 维度 | 权重 | 0 分（不合格） | 1 分（部分合格） | 2 分（完全合格） |
|---|---|---|---|---|
| 忠实性 | 25% | 答案有 chunks 之外的事实 | 核心事实正确但有延伸推断 | 完全基于 chunks |
| 答案相关性 | 15% | 答非所问 | 部分回答 | 切题精准 |
| 引用准确性 | 20% | 规范号/条文号错误 | 引用粗略 | 完整精确 |
| 完整性 | 15% | 缺核心要素 | 缺辅助要素 | 要素齐全 |
| 强制性标识 | 10% ★ | 应/宜混用（一票否决）| 用语对无标识 | 精确+标识 |
| 兜底合规 | 5% ★ | 编造（一票否决）| 告知无引导 | 告知+引导 |
| 风格合规 | 10% | 严重违反 ≥3 红线 | 违反 1-2 红线 | 完全合规 |

总分 = Σ (得分/2 × 权重 × 100)
合格线：≥ 75 分

## 评测集扩充建议

| 周次 | 新增数量 | 重点方向 |
|---|---|---|
| W3 | +50 条 | 补充隐性事实 + 跨规范综合 |
| W4 | +100 条 | 补充对抗样本 + 计算场景 |
| W5 | +50 条 | 补充用户线上 badcase（如有）|

最终达到 250 条规模，满足正式评测需求。
