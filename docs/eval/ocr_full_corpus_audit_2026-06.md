# 全语料 OCR 体检报告（89 部 / 6 域）

**日期**：2026-06-16（V2 D3）
**触发**：新域评测补覆盖时，发现 4 部缺口市政规范 chunks 重度 OCR 损伤、做不成干净评测项 → 升级为全语料体检，定 re-OCR 范围。
**结论**：⭐ OCR 损伤是**语料级、多模态**的，**廉价指标测不准**——可靠的 re-OCR 优先级无法靠自动化排出；当前定位 OCR 为"广度优先"的已知上限。字典快速收益：8 候选过 context-verify 仅 2 条幸存并已应用。

## 一、方法

| 探针 | 抓什么 | 局限 |
|---|---|---|
| `discover_ocr_errors`（LLM 生成式校对，逐部采样 3 chunk）| **同形替换**错字（管廊→管庵）+ 逐部错字占比 | 只抓干净 1:1 替换；漏汉字错乱；3 样本粒度粗 |
| 组合乱码探针（嵌拉丁 `汉字[A-Za-z]汉字` + 数字逗号 `\d,\d`，逐部 /1k 字）| **拉丁/数字乱码**（用A收、1,6MPa）| 漏汉字错乱；公式合法符号会误报 |
| PDF mtime | 新增(2026-06, 48部) vs 原始(2026-05, 41部)标注 | — |

## 二、三个核心发现

### 发现 1 · 损伤是语料级的，不是新增独有（推翻"新批烂、老批好"假设）

乱码探针均值：**原始 41 部 1.2/k ≥ 新增 48 部 0.8/k**。原始 MVP 语料同样有未清干净的损伤：

- `GB 50033-2013`（采光设计·原始）：公式被毁成「C= ×1008」「《3.0.1)」
- `GB 50180-2018`（居住区·原始·MVP 核心）：仍命中 `说→设` 等替换错字
- `GB 51039-2014`（原始）：替换 67% / 乱码 2.4

### 发现 2 · OCR 损伤至少 3 模态，没有单一廉价指标能全抓

| 模态 | 例 | 谁能抓 |
|---|---|---|
| (a) 同形替换 | 管廊→管庵、规划→规刘 | ✅ LLM 校对 |
| (b) 拉丁/数字乱码 | 用A收、1,6MPa、DN600mm | ✅ 嵌拉丁探针 |
| (c) **汉字错乱** | "机动车道按照道路…主干路次干路" → "机动车**图接长课路与王王路认十路**" | ❌ **两者全漏** |

**铁证**：`CJJ 45-2015`（道路照明）替换 0% + 乱码 0.6/k = **三项全绿**，但其 3.1.2 条正是上面那句 mode-(c) 重度乱码。**🟢 是假干净。**

### 发现 3 · 廉价指标双向不可靠 → 自动排不出可靠 re-OCR 清单

- **漏报**：mode-(c) 汉字错乱无拉丁、非 1:1 替换，两个探针都看不见（CJJ45）。
- **误报**：公式/单位密集的规范（如采光、给排水）合法拉丁符号会抬高乱码分。

→ 这张损伤表只能当**指示性下界**。要排准 re-OCR 优先级，需 LLM 逐 chunk「语义连贯性」打分（贵）或人工抽样。

## 四、字典快速收益（8 候选 → context-verify → 2 幸存）

LLM 校对出 8 个频次≥2 的系统性候选。过"占用次数 + 上下文边界"验证后**仅 2 条幸存**：

| 候选 | 判定 | 原因 |
|---|---|---|
| 指施→措施 | ✅ 采纳 | 55 处全"措施"语境；`指施工/指施设`全语料=0，无合法边界 |
| 规刘→规划 | ✅ 采纳 | 43 处全"规划"；刘=姓，"规刘"无合法成词 |
| 录→绿 / 说→设 / 高→尚 | ❌ 毙 | 高频常用单字，盲改毁"记录/说明/高度" |
| 区城→区域 | ❌ 毙 | 命中"地区\|城市""山区\|城市道路"等 **7 处合法边界** |
| 混地→湿地 | ❌ 毙 | 命中"多**混地**震"（地震语境，≠湿地）|
| 城面→城市 | ❌ 毙 | 仅出现在不可救的 mode-(c) 乱码块，低价值 |

2 条已加入 `fix_chunks_ocr.FIX_MAP` 并 `--apply` + reindex（98 处 / 94 chunk / 40 文件）。**8→2 的淘汰率再次印证启示 71：单看候选必踩红线，必须逐条查边界。**

## 五、结论与建议

1. **本轮定位**：OCR 质量是"广度优先（89 部/6 域）"换来的**已知上限**，非可一次清干净的问题。
2. **re-OCR 决策**：因 mode-(c) 廉价测不准，若未来做 re-OCR——
   - 用 LLM 逐 chunk 语义连贯打分先定 top-N（而非本报告的廉价指标）；
   - 优先 **mandatory + 含数值** 的 chunk（直接影响 RED LINE 1/3 与答案数值）；
   - `CJJ 45-2015` 等 mode-(c) 重灾区是首批候选（尽管自动指标显示"干净"）。
3. **评测侧影响**：新域市政 4 部缺口因源 OCR 损伤**暂不补评测项**（避免拿乱码当标准答案违 RED LINE 2）；市政评测覆盖保持干净 14/18。原域若干 dim5 数字 veto 实为 chunk OCR 单位损伤（answer 写对反被判错），同源。
