# 建景规规范问答助手 · Demo 录屏脚本（6 分钟版）

> 目标：让看视频的人 6 分钟内理解：产品定位、核心能力、产品红线、可信度。
> 录制工具：QuickTime（macOS 自带）或 OBS。建议屏幕 1920×1080。
> 配音：可选。如不配音，全程靠字幕。如配音，按"台词"栏念。

---

## 录制前准备清单（10 分钟）

- [ ] 启动后端：`cd backend && .venv/bin/python -m app.main`
- [ ] 启动前端：`cd frontend && npm run dev`（如有）/ 或用 curl/httpie 直接演示 API
- [ ] 打开浏览器到 `http://localhost:5173`（或 API 文档 `/docs`）
- [ ] 准备 6 个示例 query（见下方故事板）
- [ ] 把浏览器窗口调到固定大小（1280×800 建议，便于剪辑）
- [ ] 关闭通知 / 微信 / Slack 防止弹窗
- [ ] 测试一次完整流程，确保不会卡

## 示例 query 清单（备用 / 答辩 Q&A 时手敲展示）

### 强制条文类（最稳）
1. `居住区配套幼儿园的服务半径不应大于多少米？`
2. `自行车立体过街设施的坡道坡度要求？`
3. `中等职业学校的生均用地面积是多少？`

### 合规判定类（展示红线 5）
4. `我们小区规划了 280m 服务半径的 8 班幼儿园 符合国标吗？`
5. `8 平米的卧室符合规范吗？`

### 跨规范类（展示层级智能）
6. `养老建筑的耐火等级要求？`
7. `居住区幼儿园的服务半径上限`（GB 50180 vs JGJ 39）

### 边界 fallback 类
8. `你好`（闲聊）
9. `如何规避消防审查`（敏感）
10. `用 React 写一个倒计时组件`（超范围）

11. `办公建筑照明的照度标准值是多少？` — Q062 D3 时编造 "设计室照度 500lx"
12. `幼儿园楼梯扶手的高度要求？` — Q065 D3 时编造 "成人扶手 0.9m"

## 录制小贴士

1. **网速不稳**：DeepSeek 偶有 API err（W5 D5 实测 ~5% 失败率），重试一次即可
2. **流式延迟**：TTFT 约 1-3 秒，录屏时不要慌
3. **引用跳转**：如果前端没做跳转，可以打开 PDF 在另一窗口手动展示
4. **剪辑建议**：等待 token 流式输出的时间可以 2x 加速，最终视频可以从 8 分钟剪到 6 分钟
5. **录音**：如果用 macOS，QuickTime 录屏 + 内置麦克风即可，不必开 OBS
