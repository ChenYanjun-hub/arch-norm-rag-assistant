# W7 · 侧栏搜索（条文 / 对话 / 项目）

**结论**：对齐原型的搜索栏。有了项目工作区 + 会话历史后，"找回上次问过的东西"成了真实需求。
纯前端即时过滤，跨**对话正文 / 项目 / 规范**三类，命中可直接跳转。

---

## 一、设计要点

**为什么搜对话要搜正文，而不只搜标题**：
标题只取首条提问前 24 字，但用户真实的找回场景是"我记得之前哪次回答里提到过消防车道净宽"——
关键词往往在**答案正文**里，不在标题里。所以对话搜索同时匹配标题与消息正文，
并展示**命中片段**（匹配位置前后各 12 字），让用户一眼看出命中在哪、是不是要找的那条。

**搜索态替换常规分区**：搜索时隐藏「规范分类 / 项目工作区 / 历史会话」，只显示结果分组。
上下并列会让用户分不清"这是搜索结果还是原来的列表"。

**规范号搜索忽略空格**：`GB 50067` 与 `GB50067` 都能命中（规范号书写习惯不统一）。

**结果可直接行动**：
- 项目 → 选中该项目（进入其上下文）
- 对话 → 跳转到该会话
- 规范 → 切换该规范的检索限定（复用已有多选能力）
