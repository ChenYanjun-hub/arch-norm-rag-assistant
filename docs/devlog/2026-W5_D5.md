```python
for attempt in (1, 2):
    try:
        resp = client.chat.completions.create(...)
```

## 五、🎯 W5 D5 最大发现：单次 LLM Judge 50% 噪声

### Veto 翻转分析（D3 vs D5，单次跑相同流程）

```
D3 单次 veto: 35
D5 单次 veto: 38

  修复 (D3 veto → D5 OK):  18 条
  新触发 (D3 OK → D5 veto): 21 条
  持续 veto (两次都触发):    17 条
  两次都 OK:                60 条
```

### D3 + D4 + D5 三次交集分析

```
三次都触发 veto（"顽疾"）: 14 条 = 12.1% of 116
```

即：**任一单次跑的 veto 数 ≈ 真实顽疾 × 2.5x**。

### 启示 53 候选：单次 LLM Judge 50% 噪声

> 单次 LLM Judge 评分有 ~50% 噪声，必须跑 ≥ 3 次取**交集**（或多数投票）才能拿到真实 veto 集。

**等价表述**：评测的"灾难下限"信号不能信单次 — 一次跑 35 vetos 看着触目惊心，三次交集只有 14 个真顽疾。
