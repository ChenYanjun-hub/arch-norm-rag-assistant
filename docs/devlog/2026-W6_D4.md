## 二、改动 1 · align_modal_verbs 纯函数（`backend/app/rag/post_filter.py`）

### 算法：Anchor-Match

```python
def align_modal_verbs(answer, chunks_texts, *, min_match_chars=5):
    """扫描 answer 中的量词，按 chunks 原词校正不一致。"""
    1. 从 chunks 提取所有量词（应/不应/宜/不宜/可/不可/严禁/必须/不得）的 anchor:
       (pos, prefix=前 8 字, verb, suffix=后 8 字)
    2. 同样从 answer 提取
    3. 对每个 answer anchor，找 chunks 中最匹配的:
       - prefix tail 匹配数 + suffix head 匹配数 ≥ min_match_chars
       - **方向词 guard**: 如 prefix 后第一字 ∈ {大/小/高/低/...}，且 chunks/answer 方向不一致 → 跳过
    4. 如 chunks verb ≠ answer verb 且匹配充分 → 替换 answer 量词为 chunks 量词
```

### 保守策略

**方向词 guard**（最关键）：
- chunks "宜大于" vs answer "不应小于" — 简单替换会产出 "宜小于" 荒谬词
- guard 检测到方向词翻转 → **保守跳过**，不改
- 宁可 dim4 仍标错（让 Judge 报警），也不要改坏成错的中文

**min_match_chars=5**：要求 prefix + suffix 至少 5 字匹配（防误改 LLM 总结句）。

### 单测覆盖（9 个新 case，含 W6 D3 顽疾回归）

`backend/tests/test_post_filter.py` 加 29/29 tests pass：
- 基础校正：宜→应 / 不应→必须
- 语义翻转保守跳过（Q109 类型）
- 不误伤 chunks 无量词时 LLM 自由表达
- 多个 chunks 中选最佳匹配
- Q077 / Q139 真实 W6 D3 顽疾回归

## 七、🎓 启示 59 候选 · 后处理改一维可能带动其他维度（正向漂移）

W6 D4 实证：align_modal_verbs 直接命中 dim4（+3.4pp），但 dim7 **意外 +5.2pp**。

**机制解读**：
- align 把 answer 用词改回 chunks 原词
- 该位置整体变得更"忠实于 chunks"
- Judge 对该段的 dim7 评分宽松（认为"既然用词都按 chunks，编造可能性低"）
- → **维度间正向漂移**

### 对比 W6 D3 的"负向漂移"

| 实验 | 改动 | 直接命中维度 | 漂移效应 |
|---|---|---|---|
| W6 D3 fewshot | prompt +800 字反例 | dim4 ❌（+0pp）| dim3 -2.6 / dim5 -1.7（**负向漂移**）|
| **W6 D4 align** | 后处理改用词 | dim4 ✅（+3.4pp）| dim7 +5.2 / dim2/5 微涨（**正向漂移**）|

**等价表述**：
- prompt 改动是"分散注意力"型 — 容易产生负向漂移
- 后处理代码改动是"局部精准修复"型 — 容易产生正向漂移

**应用**：
- 优先后处理（精准），慎用 prompt（弥散）
- 每次改动都要全维度评估（不只看主目标维度）

## 十一、AIPM 启示候选

### 启示 59 候选 · 后处理改一维可能带动其他维度（正向漂移）⭐

W6 D4 align_modal_verbs 实证：
- 主目标 dim4 +3.4pp（直接命中）
- 意外副产品 dim7 +5.2pp（间接受益）

机制：用词改回原词 → 该段"忠实度"上升 → Judge 对其他维度也宽松。

**对比启示 51（W5 D4）**：W5 D4 4 条 prompt 约束中"直接命中 dim3 +2.5pp"
也属于此类，但 W6 D4 是"间接漂移 +5.2pp" 比"间接微涨 +0.9pp" 强得多。

**应用**：
- 选择改动手段时优先评估"漂移特征"（正向 vs 负向 vs 零）
- 后处理代码改动天然是"局部精准修复"，正向漂移概率高
- prompt 改动是"分散注意力"，负向漂移风险高（W6 D3 实证）

### 启示 60 候选 · 后处理链式叠加的合规性

W6 D4 验证两层 post_filter 链式叠加（strip → align）效果良好：
- 单独 strip：dim7 +11.2pp（W6 D2）
- 单独 align：dim4 +3.4pp（W6 D4 直接）
- 链式叠加：dim7 +9.5pp + dim4 +5.2pp（vs v1.0-mvp）

**等价表述**：post_filter 工程模式可以无缝叠加，每加一层治一个 LLM 训练惯性。
未来 W7+ 可以继续加（如 _align_numbers、_strip_strong_claims）形成"后处理矩阵"。
