# W7 · 导出报告

**结论**：把"可追溯引用"这个核心价值变成**可交付物**。规划师查完规范要把结论放进设计说明/方案文本，
审图时必须能指回"这条依据是哪部规范第几条第几页、现在还有没有效"——报告就是这最后一公里。

---

## 一、产品判断

**报告里什么最重要？** 不是答案本身（那能复制粘贴），是**依据的可追溯性**。所以引用清单里
规范全称 / 标准号 / 条文号 / 页码 / 强制性标记 / 现行状态 一个都不能少，还要带**原文摘引**——
审图人看的是原文，不是 AI 的转述。

**格式选 Markdown**：零新增依赖、可直接粘进 Word/飞书/Notion。
Word/PDF 需要引入第三方库（python-docx / reportlab），按 CLAUDE.md G.1 属"引入新库需先请示"，本轮不做。

**两处红线相关的设计**：
1. **含非现行规范时显式告警**——条目内标 `⚠️ 已废止，现行替代：XXX`，并在该轮末尾汇总
   "本轮引用中含 N 条非现行规范，引用前请核对现行版本"。审图会看这个。
2. **免责声明必带**——"AI 检索生成，非官方发布物；不构成合规结论，请咨询规划主管部门或专业审图机构"。
   这直接对应红线 4（不下合规结论）。
3. **引用核验的待核项一并导出**——verifier 发现的疑似无据项属于"必须随报告交付的风险信息"，
   不能只留在界面上。

## 二、实测（拦截 Blob 校验真实内容，不只是"按钮能点"）

导出的报告实际包含：

```
# 规范查询报告 · 防火墙的耐火极限要求是多少？
- 生成时间 / 会话时间
- 所属项目：深圳前海T3地块
- 项目规范范围：DB 31T 1695-2026、GB 50067-2014
- 生成工具：建景规·助手（AI 检索生成，非官方发布物）
## 1. 防火墙的耐火极限要求是多少？
   （答案正文）
### 依据条文（5 条）
1. 《建筑防火通用规范》GB 55037-2022 6.1.3
   - 第 29 页 · 消防域 · **强制性条文**
   - 原文摘引：“6.1.3防火墙的耐火极限不应低于3.00h。…”
   …
**免责声明**：…
```

**废止告警分支**（当前语料无废止规范，故用注入假数据验证后还原）：
```
- 第 16 页 · 消防域 · **强制性条文** · ⚠️ **已废止**，现行替代：GB 55037-2022
- 状态说明：2023-06-01 废止
> ⚠️ 本轮引用中含 1 条非现行规范，引用前请核对现行版本。
```

> 测试插曲：第一次验证废止分支时输出为空——查下来是我把假数据注入到了**非激活会话**，
> 而导出的是当前激活会话。**是测试打错了对象，不是代码问题**；切换会话后验证通过。

console 无报错、build 通过。
